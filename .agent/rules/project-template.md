# Rule 05: プロジェクト固有の遵守事項（wsl-home）

> 優先度: **HIGH** — `AGENTS.md §6` のチェックリスト版。§6 と本ルールが食い違ったら §6 を正として両方を整合させる。
>
> 本ファイルはテンプレートの記入欄でしたが、2026-10-19 の取り込み時に wsl-home 用に記入済みです。
> 事実・前提の詳細は [`project-overview`](../skills/project-overview/SKILL.md) と [`wsl-dotfiles`](../skills/wsl-dotfiles/SKILL.md) を参照してください。

## 1. 環境・ツールチェーン（§6.1相当）

- 対象: WSL Ubuntu 向け dotfiles（zsh / 設定ファイル / 配置スクリプト）。現在は設計段階で、ビルド対象はありません。
- 環境は 2 つ（AI 作業環境 / ユーザー実環境 `/home/ubuntu`）。混同しません。
- 検証コマンドは `AGENTS.md §6.1` の記録だけを使います（hooks の構文・`settings.json` の妥当性・symlink・内部リンク等）。`zsh -n` 等の実環境側検証はユーザー実施として切り分けます。
- 配置スクリプトの検証コマンド（dry-run 等）は設計合意後に §6.1 へ記録してから使います。未記録のコマンドを案内しません。

## 2. サンドボックス制約（§6.2相当）

| 制約 | 対処 |
|---|---|
| ユーザー実環境へ直接アクセスできない | 変更は本リポジトリへの commit まで。反映手順は別途提示する |
| AI 作業環境に `zsh` 等がない（2026-10-19 実測） | `sh` 範囲の検証に留め、zsh 固有検証は未実施と明示する |
| 参照リポジトリは外部にある | 読み取り用 clone のみ（実行・source しない）。本リポジトリへ取り込まない |

## 3. リポジトリ固有の Git 制約（§6.3相当）

- 本リポジトリは公開（2026-10-19 確認）。秘密鍵・`.env`・トークン・履歴・個人情報をコミットしません（`.gitignore` で除外し、`git diff` で最終確認）。
- Git の名前 / メール等の個人設定は含めません。参照用 clone や生成物もコミットしません。

## 4. 実装ルール（§6.4相当）

- 設計合意前に、実環境の変更や「確定仕様」の作り込みをしません。
- 合意済み: 実体 1 つ + ホームからの一方向シンボリックリンク（詳細は `wsl-dotfiles` スキル）。
- Starship の見た目と既存ツール構成は変えません。参照先は無条件コピーの対象ではありません。
- 未決事項は `AGENTS.md §6.4` のリストを正とし、ここでは決定しません。

## 5. Lint・フォーマット特有ルール（§6.5相当）

- 自動フォーマッタ・Lint は未導入です。導入時は §6.1 へ記録してから使います。
- `.sh` は POSIX sh で書きます。設定ファイル名はツールの定める名前が命名規約に優先します。

## 6. 成果物・表現ルール（§6.6相当）

- 対話と報告は `AGENTS.md §7`（日本語）に従います。
- バージョン・パス等には確認日と出所を添え、未確認は「未確認」と明示します。

## 7. ドキュメント運用（§6.7相当）

- `docs/` は未導入です。正本は `AGENTS.md §6` / `project-overview` / `wsl-dotfiles` / `.agent/rules/` / `.agent/logs/` です。
- スキル・ルール・フックを変更したら対応する `index.md` を更新します。
- `docs/` を導入するときは、本ルールと `01_information-hierarchy.md` / `03_doc-style.md` の前提を一括で整合させます。
